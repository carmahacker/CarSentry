«До исчезновения номера» — один Event, пока этот номер продолжает распознаваться. Новое срабатывание после отсутствия номера указанное количество секунд. «Кулдаун» — повтор блокируется на указанное количество секунд независимо от дальнейших распознаваний.
Webhook при совпадении номера
Webhook выполняется только после успешного распознавания номера и только при точном совпадении с номером-триггером. Повторное срабатывание блокируется кулдауном номера, который хранится в SQLite.
